## How to read these documents

Use the [project overview](../../README.md) for a quick introduction and the [technical guide](../../ADRpy/analisis/README.md) for the current implementation and its limitations. The PDFs preserve the academic narrative, including broader architecture and claims that do not all match the checked-out code: MAE, uniform validation, complete traceability and automatic ADRpy input generation should not be inferred as implemented capabilities.

The [separate ADRpy case-study notebook](../ADRpy/notebooks/ADRpy_Tesis_Delpino.ipynb) uses manually defined inputs for conceptual constraint analysis. Its values, units and assumptions require review before reuse; it is not an automatic output of the design assistant.
